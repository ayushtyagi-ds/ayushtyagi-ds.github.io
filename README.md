# Ayush Tyagi - AI-Assisted Developer Portfolio

A modern, professional multi-page portfolio website showcasing data science and engineering expertise.

## 🚀 Features

- **Multi-page layout** with dedicated sections (Home, About, Projects, Experience, Contact)
- **Dark theme** with modern aesthetics and smooth animations
- **Fully responsive** design for desktop, tablet, and mobile devices
- **Interactive elements** including project filters and contact form validation
- **SEO optimized** with proper meta tags and semantic HTML
- **Fast loading** with optimized CSS and JavaScript

## 📁 Structure

```
/
├── index.html          # Home/Landing page
├── about.html          # About page with skills and education
├── projects.html       # Projects showcase with filtering
├── experience.html     # Professional experience timeline
├── contact.html        # Contact form and social links
├── css/
│   └── style.css      # Main stylesheet
├── js/
│   └── main.js        # JavaScript functionality
├── images/
│   └── README.md      # Instructions for adding images
└── assets/
    └── resume.pdf     # Downloadable resume
```

## 📝 Customization

1. **Personal Information**: Update name, email, and social links in all HTML files
2. **Projects**: Edit `projects.html` to add your own projects
3. **Experience**: Modify `experience.html` with your work history
4. **Skills**: Update skill sets in `about.html`
5. **Resume**: Replace `assets/resume.pdf` with your actual resume
6. **Favicon**: Add `images/favicon.ico` (use https://favicon.io/)
